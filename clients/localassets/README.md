# 本地资源模型查看器（localassets）

一个用来查看本地 MDX/MDL 模型的小客户端：把模型拖进来，再告诉它去哪儿找纹理。

运行：

```
yarn run serve
```

然后打开 <http://localhost:8080/clients/localassets/>（用 `yarn run dev` 只做 watch 构建时，页面同样从这个地址加载 `/clients/localassets.min.js`）。

## 资源来源与优先级

从高到低：

| 优先级 | 来源 | 说明 |
| --- | --- | --- |
| 1 | **拖入的文件** | 直接拖到页面上的文件或文件夹。模型自己也在这里，所以和模型一起拖进来的纹理永远优先。 |
| 2 | **纹理目录** | 「添加…」选择的目录，可以添加多个，并用 ↑ ↓ 调整顺序。 |
| 3 | **MPQ 归档** | 「选择游戏目录…」后自动找出的 `*.mpq`，或手动添加的 MPQ。**优先级最低**，只在前面都没有命中时才会用到。 |

同一个来源内部，请求 `Textures\Foo.blp` 时的查找顺序是：

1. 相对于模型所在目录的完整路径（模型是连着文件夹一起拖进来的时候有用）；
2. 相对于来源根目录的完整路径；
3. 把扩展名换成 `.dds`/`.tga`/`.png`… 后的上述路径（SD/HD 混用时会自动救回来）；
4. 任何位置的同名文件（优先选择路径结尾与请求一致的）。

所以「把模型单独拖进来 + 配置一个游戏目录」就能看到带纹理的经典模型，而「把模型和它的纹理文件夹一起拖进来」会优先使用拖进来的纹理，不会被 MPQ 里的同名文件覆盖。

## MPQ 层

- 归档查找顺序：`War3Patch.mpq` → `War3xLocal.mpq` → `War3Local.mpq` → `War3x.mpq` → `War3.mpq`，其它归档排在最后。补丁与本地化归档覆盖基础归档。
- 归档是**按需解析**的：某个文件查不到时会依次加载下一个归档，所以只配游戏目录、不加载任何模型时不会读任何归档。
- 解析一个归档需要把它整个读进内存（库的限制），整套经典安装可能超过 1 GB。不需要的归档可以在列表里取消勾选，或者直接删掉。
- 1.30 及以后的安装使用 CASC 格式，本客户端不支持，只能用 1.27 及更早的经典安装目录。

## 其它

- 拖入 `.mdx`/`.mdl`，以及整个文件夹（会递归读取）。拖入的文件里只要有模型，就会自动加载第一个；拖入纹理时也会顺带重新加载当前模型。
- 拖进来的模型会列在面板里，点一下即可切换；文件夹里有很多模型时很方便。
- 动画下拉框、播放/暂停、队伍颜色切换；左键旋转、右键平移、滚轮缩放。
- **模式**：默认按模型的版本自动判断（版本 > 800 视为 Reforged，用 28 组队伍颜色）。查看器会按模式构建，切换模式或点击「重新加载」时会用新的 canvas 重建，从而清空缓存并重新解析所有纹理——改了来源之后点它即可。
- 日志区会显示每个路径是**从哪个来源**命中的，方便排查缺纹理的问题。
- 控制台里可以直接拿到内部状态：`localAssets.viewer` / `localAssets.camera` / `localAssets.mpq.archives` / `localAssets.missing`。

## 实现

| 文件 | 作用 |
| --- | --- |
| `resolver.js` | 路径归一化、候选路径/扩展名回退、按优先级解析来源。不依赖 DOM 和查看器，可以在 Node 里测试。 |
| `mpqsource.js` | MPQ 层：归档的惰性加载、按优先级查询、按 (listfile) 做同名回退。 |
| `index.js` | 查看器、拖放、目录选择与面板的接线。 |

## 测试

`resolver.js` / `mpqsource.js` 有一套 Node 测试，会用库自己的 MPQ 写入器生成真实归档再读回来，覆盖候选顺序、扩展名互换、同名回退、归档优先级、惰性加载和来源优先级。因为客户端代码是 ESM 且引用了 TypeScript，需要先打包再跑：

```
node node_modules/webpack/bin/webpack.js --mode=development --target=node \
  --entry ./clients/localassets/test/logic.test.js --output-path ./dist/test/localassets
node ./dist/test/localassets/main.js
```
